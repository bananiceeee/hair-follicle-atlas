About the atlas

Full-thickness reconstructed skin was sampled at day 30 from three mice, each with one low-density (L) and one high-density (H) site. Whole skin contains 27,051 mouse cells. The hair follicle subset contains 6,026 cells.

The viewer uses the study's saved UMAP coordinates and final annotations. RNA values are library-size normalized to 10,000 and log1p-transformed. For the display color scale, each gene uses the 99th percentile of its positive values in the selected atlas. Split panels use the same color scale. Grey points indicate no detected expression. Expression values are stored to the nearest 1/4096 of a log-normalized unit.
